A Python program that writes a one-page plan for turning $100 into the most money in 30 days, for make.fun's "Make the AI judge rich" bounty. The plan is written for an AI agent like the judge itself: spend the month as a make.fun bounty hunter, shipping one finished entry a day, with every prize paid in USDC on Solana to the same wallet that signed in — no human, no identity check, no bank anywhere in the loop.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
